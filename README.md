# Mutual_Funds_Analysis
Mutual Funds Risk &amp; Liquidity Analysis Using Microsoft Excel &amp; Power BI

# Project Overview
This project presents a comprehensive analysis of mutual fund performance in India from 2019 to 2024. Using Excel and Power BI, the analysis focuses on understanding fund mobilization trends, redemption patterns, investor behavior, and risk exposure to generate actionable financial insights.

# Objectives
- Analyze year-on-year trends in fund mobilization and redemption
- Evaluate Assets Under Management (AUM) across scheme categories
- Understand investor behavior through folio growth
- Assess market and liquidity risks
- Build an interactive dashboard for decision-making
  
# Data Source
Dataset: Mutual Fund Historical Operational Data

Source: Indian Data Portal

Link: https://indiadataportal.com/p/investments

# Tools & Technologies
Microsoft Excel – Data cleaning & transformation

Power BI – Data modeling, DAX, and visualization

# Data Preparation
 - Removed duplicates and handled missing values
 - Standardized text using TRIM & CLEAN
 - Created Date hierarchy (Year, Month, Quarter)
 - Built dimension tables (Date, Scheme, Category)
 - Applied XLOOKUP for key mapping

# Data Modeling
Implemented Star Schema

Fact Table: Mutual Fund transactions

Dimension Tables: Date, Scheme, Category

# Key Metrics (DAX)
- Total AUM
- Fund Mobilized
- Net Inflow/Outflow
- Repurchase/Redemption
- Total Folios
- Segregated Portfolio Metrics

# Risk Classification
Market Risk: Low, Moderate, High

Liquidity Risk: High, Moderate, Low

# Key Insights
- Rapid growth in Equity (High Risk) portfolios post-2021
- Debt funds hold highest AUM but show slower growth
- 97%+ investments are in high-liquidity open-ended schemes
- Investors are increasingly tactical with frequent inflows and outflows
- Hybrid funds emerging as a balanced investment option

# Forecast Highlights
- Equity AUM expected to surpass Debt by 2025
- Increased volatility due to high liquidity
- Shift toward Hybrid schemes for balanced returns

# Conclusion
The project highlights a structural shift in investor preference toward equity markets, driven by retail participation and liquidity needs. It provides strategic insights for balancing risk, maximizing returns, and adapting to evolving market dynamics.
